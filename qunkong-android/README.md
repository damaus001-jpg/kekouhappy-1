# 安卓短信管理开发约定

记录日期：2026-11-22；项目恢复版本：v0.1.23。

## 已确认范围

- 安卓相关源码、配置、资源、构建和研究资料统一放在本目录。
- 初期只使用一台安卓手机测试，不要求投屏。
- 暂时用本机电脑作为服务器，手机通过局域网连接；执行任务时电脑保持开机和后台运行。
- 手机安装自行编译和签名的 APK。后台、数据库、设备接入和调度均自行部署，源码与数据可控。
- 集中管理短信收发、任务分配和发送节奏；后续考虑多设备、SIM 选择、发送间隔、额度、定时、暂停、状态回传和防重复执行。
- 息屏运行是待验证要求，需检查后台权限、电池优化、自启动及长时间连接稳定性。

## 下一步

先核查以下候选的许可证、自建部署方式、第三方依赖及能否脱离作者云服务独立运行，尤其检查 Firebase/Google 推送依赖与替代方案；尚未选定方案。

- TextBee：https://github.com/textbee/textbee
- SMSGate 手机端：https://github.com/capcom6/android-sms-gateway
- SMSGate 网页后台：https://github.com/android-sms-gateway/web-dashboard

选型后在本机部署后台，自行构建 APK，以一台手机跑通注册、短信接收、明确授权的发送测试、息屏执行、状态回传和间隔调度。实测稳定后再扩展多设备。
