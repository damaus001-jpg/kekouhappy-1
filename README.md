# 项目恢复

当前版本 **v0.1.20**，本地恢复标签 `v0.1.20`，见 [本次存档](SESSION_ARCHIVE_2026-11-21_v0.1.20.md)。本次修复设备重连时目标 USB 隧道残留问题，并保存此前已完成的皮卡丘主题联动与新消息横幅工作。v0.1.20 新安装包尚待用户完成 11–18 设备检查后构建。后台启停接入说明见 [接入协议](PIKACHU_8070_CONTROL_PROTOCOL.md)。

v0.1.19 后台专用安装模式内置 Python、Node、C++ 运行库和项目依赖，不再提供独立 Electron 客户端及启停快捷方式。皮卡丘从当前用户注册表发现实际安装目录，通过签名命令查询、启动、彻底关闭；原有苹果入口负责显示页面。安装模式下直接运行后台会拒绝启动。此限制针对常规入口绕过，不构成对同一 Windows 用户修改程序或读取密钥的安全隔离。安装器及验证方法见 [打包说明](tools/PACKAGING_8070.md)。Apple USB 驱动、手机信任和开发者模式仍需在目标电脑首次准备。未推送远端；从 GitHub 运行恢复脚本取得的版本以远端实际内容为准。

8070 实时画面旁竖排设备号的顶部新增蓝底白字“新建短信”入口。弹窗沿用深绿主题，可导入 TXT、自动规范号码与去重、编辑逐行文本库、勾选设备并分别配置固定/随机间隔、设置立即/定时开始和同时操作设备数。当前交付阶段仅支持保存与恢复配置草稿（保存在当前浏览器本地存储），不会创建或启动发送任务；正式任务存储、号码唯一领取、定时执行、多设备发送调度及 Windows 通知尚待接入。浏览器界面检查使用 795 个号码、50 条文本和 20 台模拟设备通过，不代表 20 台实机并发已验收。刷新页面即可加载该入口，无需为本次 UI 更新重启后台。

在联网的 Windows 11 x64 电脑运行 `Recover.ps1`，即可从 GitHub 下载项目、安装环境并启动；完整步骤见 [RECOVERY.md](RECOVERY.md)。

8070 工作台的“截屏”按钮提供两种方式：左侧“手机本机截屏”发送系统截屏指令，图片保存到手机相册；右侧“实时画面截屏”截取当前投屏画面，以 PNG 另存到电脑，可选择文件夹和文件名。不支持“另存为”或浏览器拒绝直接写入时，改用下载保存，并提供“重新下载这张截图”按钮；拒绝直接写入后，当前浏览器后续使用下载保存。下载位置由浏览器设置决定，需要选择文件夹时可开启“下载前询问保存位置”。更新后刷新工作台；原生截屏的新后端接口需重新启动对应设备的投屏进程（可使用“重新连接此设备”），或重启工作台后台后生效。手机本机截屏已于 2026-11-20 由用户实机验收通过。电脑保存流程通过模拟测试和真实浏览器 PNG 解码检查，修复后的电脑截屏保存已于 2026-11-20 由用户验收通过。

8070 工作台支持在设备右键菜单选择“重启此手机…”。确认设备编号与名称后，仅向该手机发送一次重启指令；开机后需在手机输入密码解锁，工作台随后尝试恢复画面与操控。更新此功能后需重启工作台后台并刷新页面。2026-11-20 设备 1 实机重启后约 75.5 秒恢复就绪，用户确认画面、点击、滑动和键盘输入正常。

连续按住拖动可能使空闲健康检查无法运行，旧实现的 30 秒就绪有效期随之过期，并拦截松手指令而残留触摸。现以已成功执行的输入更新就绪时间；仍处于控制中的设备允许在未就绪时发送松手、松键清理，新的按下操作继续受就绪检查限制。修复后需重启工作台后台并刷新页面，连续拖动的实机回归待验收。

点击“此设备待跟进号码”打开会话时，优先只读短信页底部控件：左下角“搜索”判定为短信列表，左下角“＋”（AX 名为 add）判定为会话页；不读取顶部、不遍历短信条目。列表识别后还需确认右下角“新建短信”按钮才执行新建。会话识别与草稿、发送按钮可用状态分别判断，控件组合冲突时返回未识别。设备 1 于 2026-11-20 只读实测 3 个底部元素识别为列表，扫描约 0.214 秒，含服务连接共约 0.934 秒。已有会话的草稿保护、返回列表和收件人核验保留；快速定位无法确认页面时使用原有核验路径。此脚本每次操作重新加载，无需为该优化重启后台。

2026-11-20 在设备 1 的持续通知横幅上完成只读 AX 定位：普通 MobileSMS 焦点遍历不含横幅；通过 USB `OsTraceService.get_pid_list()` 查出 SpringBoard PID，将 AX 审计目标临时设为该 PID 后，`deviceFetchSpecialElement: 1` 返回标识为 `NotificationShortLookView` 的实时元素。仅设置检查器焦点（`deviceInspectorFocusOnElement:`，不是 Activate）后，其焦点事件和 Label 属性返回短信来源、相对时间、发件号码和预览正文。`_AXHierarchyElementsAttribute` 的子节点为 `ShortLook.Platter`；解码需在探测进程内注册 `AXAuditNode_v1`，不改安装库。此次未点击、展开通知或切换会话；未读标志/对端已读回执尚未独立验证。此结果仅证明通知预览可读，不代表完整会话历史可从横幅取得，也尚未接入设备新消息提示。系统 PID、元素令牌必须每次取实时值，不可沿用本次设备 PID。探测记录见 `.tmp/notification-banner-attributes.json`，脚本为 `.tmp/probe_ax_banner.py`。
