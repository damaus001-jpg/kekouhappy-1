# 阅读区粘贴与前台会话自动读取

本功能只属于原 8070 工作台。平级 VNC 项目仅用于只读对照，没有加载或修改其开发源码。

## 使用方式

- 阅读区 Enter 与“粘贴到手机”调用同一个函数：写入手机剪贴板后发送粘贴快捷键，不再每次扫描并重新点击输入框。它依赖手机当前已聚焦目标短信输入框；切换会话或焦点丢失后，先在手机画面点一次输入框。回执只表示快捷键已发出，不代表应用已接收；需核对手机输入框后手动发送。正文保留，不附加 Return，不调用发送接口。
- Shift+Enter 换行；输入法选字确认和按键长按重复不会重复粘贴。“确认发送”保留原收件人和正文核验。
- 当前大屏手机操作区可见且允许操作时，可以预热该设备的 AX 连接。预热只连接服务，不扫描元素、不启用应用元素监听、不移动手机焦点；空闲连接不持有全局 `phone_lock`。
- 只有当前大屏手机画面内完成的一次主按钮点击，在触摸释放请求成功后再等待 0.5 秒，才触发一次号码探测。设备列表、阅读区、工具栏点击均不触发；拖动、滚轮、取消、释放失败和已失效的点击也不触发。等待期间新的手机操作、切换设备或失去控制会取消旧点击。
- 每次点击最多检查三个 AX 元素，从 First 开始向下。未命中、繁忙或出错即停止本次寻号，等下一次大屏点击；识别成功即停止寻号，先更新该号码的已保存记录，再进入当前消息读取。
- 本轮保存后等待更新，约每两秒安排一次有界尾部检查。它独立于原“自动遍历”通知扫描开关，只处理当前大屏手机。
- 手机画面的滚轮或垂直拖动会持续暂停自动读取；点击“恢复自动读取”重新启动。电脑阅读区上翻历史不暂停采集，新增内容保留原阅读位置。
- 电脑草稿、手机非空草稿、按住的鼠标或键盘、粘贴、手工读取、切换手机和隐藏窗口会让自动任务暂停或取消。

## 读取与数据边界

单次寻号最多检查三个顶部控件，扫描预算 0.8 秒；没有定时寻号或未命中重试。前端的 0.5 秒调度只维护预热、暂停状态及已识别会话的消息更新，不会自行启动寻号。只接受中英文会话标题中的完整号码，不把正文号码当成身份。未收到焦点移动确认时不连续发送 Next；点击探测不做 First 恢复或第二轮扫描。

尾部扫描最多 32 个控件、扫描预算 1.5 秒；补读从底部倒序，最多 600 个控件、扫描预算 18 秒。连接、初始化及清理另有整体超时。图片保留为附件占位，日期按实际分隔记录，相同文字的不同出现不按文本去重。

有历史时必须与已保存的尾部唯一衔接。歧义窗口单独保留，旧历史和有效缓存不被覆盖。允许一次扩大范围重试，仍不能确认则等待变化或人工读取，不无限重复长遍历。尾部观察值与已保存检查点分开；只有存储成功且与已保存历史核验一致才能推进检查点。

每个浏览器任务携带设备和递增任务标记；过期、已取消或设备不再允许操作时的结果不更新阅读区。点击探测与后续读取复用预热的 AX 连接，只有连接准备和实际操作期间取得原有手机操作锁，空闲时释放锁。切换设备、隐藏页面或页面关闭时取消旧任务并请求释放旧会话；旧代次的释放不能关闭更新代次已使用的连接。连接初始化、操作和服务清理均有界；取消等待 AX 清理完成，异常连接丢弃后由下一次操作重新准备。页面退出的释放依赖浏览器 keepalive 请求成功送达，后台退出也会清理会话。

自动路径不调用数据库备份、发送、触控手势或翻页接口。AX 焦点移动本身仍可能改变手机可见位置，不能承诺完全无干扰。当前人工活动信号来自工作台转发的操作，不代表已经检测手机实体上的所有触摸。尾部检查没有永久消息标识，不能承诺任意数量、完全相同内容的新消息都能零遗漏；无法唯一确认时保留未完成状态。数据库完整历史仍由用户明确点击原按钮同步。

自动保存的、已核验身份与有界读取上下文的记录使用原发送上下文指纹格式；未知气泡或读取未完成的记录不会伪装成可直接发送的完整上下文。自动流程本身不发送消息。

## 通知中心扫描的页面核验

原“自动遍历”通知检查必须同时取得两个不同的原生 AX 按钮：手电筒和相机。通知中心标题、单个按钮或手势成功返回都不能代替这对控件。匹配使用中英文原生按钮身份，不调用截图、OCR 或视觉模型；当前焦点接口没有稳定暴露这两个按钮的位置，因此不宣称已经核验像素坐标。

打开前及下拉后先做最多十二个控件的有界核验，必要时从末端检查快捷按钮；确认后才完整读取通知。若下拉失败仍在短信列表，或完整扫描中遇到短信列表/会话标识，立即停止，原通知卡片和上次成功检查时间保留，不记为“没有通知”。离开页面时也要重新确认快捷按钮，不能盲目补一次上滑。

连续失败的设备分别至少等待十五、三十、六十秒后再重试，之后保持六十秒；成功后重置。手动重新开启原开关会重置等待。此规则只针对通知检查，不会重新触发前台寻号，也不改变已识别会话的消息增量读取间隔。

## 验证

仓库已有离线检查涉及标题误识别、图片和重复气泡、格式化号码、取消清理等；部分前台调度检查仍基于旧的自动寻号行为，不能作为本次点击触发逻辑已经通过的证据。本次按要求只做代码与差异静态检查，未运行测试、未启动后台验收、未连接或操作真实手机。

`test_foreground_browser.cjs` 仅启动本地模拟手机和无界面浏览器，验证缓存联动、更新阅读区、回车原文粘贴、草稿保留、阅读位置保持和手机滚动暂停/恢复；不会连接 USB 或发送短信。模拟截图留在忽略的数据目录。

这些检查不等于真实手机验收。上线使用需要重启 8070 后台并刷新工作台，实机确认 AX 标题与气泡事件、取消时延、滚动影响和输入框定位。本次没有重启手机服务、没有发送短信、没有提交 Git 或建立恢复点。
