# 设备9局部焦点路径与高亮范围核验

承接 [逐事件观测](AX_EVENT_OBSERVATION_2026-11-18.md)，本次围绕13:05附近做局部实验，同时核对用户观察到的半透明焦点框覆盖不完整现象。

## 焦点框与识别结果的关系

焦点框表示当前 AX 节点的范围。节点可能对应完整气泡，也可能对应正文、图片或按钮子节点；长气泡也可能部分位于屏幕之外。因此“框完整覆盖气泡”不能作为采集成功的充分条件，框未完整覆盖也不能单独证明漏读。

应分开核验：

1. 单条记录：正文或附件类型、方向、实际取得的时间以及字段来源。缺失字段保留未知。
2. 序列完整性：跨窗口的上下文是否连续，是否存在回退、重复路径、跳到输入框等异常。两遍一致也不能证明不存在共同漏项。
3. 画面一致性：焦点所处区域与返回文本是否对应。框异常属于补查信号，不代替前两项核验。

## 实验一：容器与子节点

方式：从底部反向寻找已确认13:05气泡，再向下最多18步。反向仍用包含容器、160ms静默等待；局部下行分别包含容器或只走子节点，静默等待210ms。定位和每组实验都设上限，结束独立回到底部。没有点击图片、保存照片或激活按钮，Save photo 只是被动读到的节点。

在起点、下行第6和12步截图。截图会引入额外停留，因此本组只用于路径和画面比较，不能作为两种方式的速度对比。

| 样本 | 结果 |
| --- | --- |
| 包含容器，第1次 | 完成18步；先经过13:18，再回到13:00附近，随后推进到13:22 |
| 只走子节点，第1次 | 完成18步；13:18后返回13:11，后来推进到13:24 |
| 包含容器，第2次 | 有界反向定位未获得13:05完整目标，局部实验未开始；不能纳入有效对照 |
| 只走子节点，第2次 | 完成18步；仍有回退，但读到了此前缺失的13:25正文，最后到13:26 |

总耗时174.841秒，包括反向定位、截图和每次回底。四次尝试最终均确认回到已知09:07底部。

截图实际检查：

- 包含容器第1次起点：13:05气泡在画面中可见，框仅覆盖其局部区域。
- 同一组第6步：焦点位于设计图说明附近，确认发生了实际位置回退。
- 同一组第12步：返回文字为较早正文片段，截图中的高亮范围位于后方照片区域附近。该不一致需要保留为异常证据；尚未证明由哪一层缓存或布局行为造成。
- 子节点第1次第6和12步：截图分别在13:11附近及后续人物照片/13:22消息附近，与中途返回较早节点、随后继续推进的路径相符。

结论：切换 includeContainers 不能直接消除回退。局部只走子节点有时能读到此前漏项，但目前有效样本少，不能宣布其全面优于容器方式。

## 实验二：实时 Label 查询和非文本等待

为避免截图在中途引入停留，本组只在局部遍览结束后截图。两种配置交替重复两次：

- 子节点基线：210ms静默等待；遇到部分非文本节点查询同一节点 Label 两次。
- 子节点等待：上述查询之间增加800ms等待；只在 Message, Button、Save photo 或独立 Image 条件命中时增加。

这不是纯粹的“仅睡眠差异”实验：两种配置均比先前增加了 Label 查询，其耗时也可能影响导航。分析已记录实际触发次数，不能根据配置名称认定每组都执行了800ms等待。

| 样本 | 局部结果 | 实际增加等待 |
| --- | --- | --- |
| 基线第1次 | 18步，读到13:25，最后到13:26 | 0 |
| 等待第1次 | 9步后跳到输入框，连续性未证明，记录为未完成 | 0；该路径没有命中指定条件，不能用来判断800ms效果 |
| 基线第2次 | 18步，读到13:25，最后到13:26 | 0 |
| 等待第2次 | 18步，读到13:25及13:27，随后仍返回13:24 | 2次，共1.6秒 |

总耗时137.943秒，四次最终均确认回到底部。实际执行额外等待的样本仅1次，且仍有回退，未形成最优等待时长或稳定恢复策略的结论。

## 可复现的字段补全证据

实验二3次局部遍览中，图片焦点事件返回 `Message, Button` 或 `Message, Button, Image`。同一节点连续两次查询的 Label 一致，返回对方号码、Includes picture 和13:22。

把 Label 本身作为独立来源交给既有解析器，确实得到 incoming / 13:22 / attachment / Includes picture 的候选记录。方向与时间来自实际查询结果，没有根据相邻消息猜测。

这说明对部分不完整节点进行属性查询有价值。它仍有边界：

- 这是同一张13:22图片的3次局部复现，不是3类不同附件的验证。
- Label 可能截断，长正文及其时间仍需另外核验。
- 元素句柄可能被复用；真实消息合并仍需核对上下文、来源和出现次数。
- 候选补全结果只写入诊断分析，没有写入正式消息库或修改自动遍览。
